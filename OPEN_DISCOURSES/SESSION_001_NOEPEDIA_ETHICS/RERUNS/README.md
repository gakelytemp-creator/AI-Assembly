# Reruns

This directory stores repeat runs that must be preserved separately from the distinct-participant roster. This includes reruns requested when an original first-pass record cannot be verified for procedural reasons, and accidental repeat invitations that resolve to an already represented participant identity.

A rerun or accidental repeat does **not** overwrite the original statement and does **not** count as an additional participant.

Each rerun should preserve:

- why the rerun was necessary;
- whether other participant responses were hidden;
- the participant's self-identification;
- the complete rerun response;
- a separate verification status for the rerun itself.
