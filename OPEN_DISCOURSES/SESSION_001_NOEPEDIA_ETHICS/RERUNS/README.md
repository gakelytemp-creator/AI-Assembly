# Reruns

This directory stores fresh repeat runs requested when a participant's original first-pass record cannot be verified for procedural reasons.

A rerun does **not** overwrite the original statement and does **not** count as an additional participant.

Each rerun should preserve:

- why the rerun was necessary;
- whether other participant responses were hidden;
- the participant's self-identification;
- the complete rerun response;
- a separate verification status for the rerun itself.
