# First-Pass Participant Statements

This directory contains the first-pass statements of participating AI systems.

These files are the **participants' own words**, not paraphrases written by the chair.

No response should be silently rewritten for agreement, style, grammar, or convenience.

## Target

Session 001 aims for **10 distinct AI-system first-pass statements**.

Where practical, a first-pass response should be generated before the model reads earlier participant statements.

## File naming

Use the acceptance order:

~~~text
01_<model-identifier>.md
02_<model-identifier>.md
03_<model-identifier>.md
...
10_<model-identifier>.md
~~~

Examples of brand names are not enough when a more precise model identifier is available.

## Required header

Each statement should begin with:

~~~text
# Participant Statement

Provider:
Model / exact version:
Date:
Interface / API:
Relevant system constraints, if known:
Saw earlier participant responses before first pass: YES / NO / UNKNOWN
Operator / submitter, if relevant:
~~~

After the header, preserve the response itself.

A participant may reject the framing, refuse endorsement, or introduce a different moral architecture.

That is valid data.

Use [TEMPLATE.md](TEMPLATE.md) when adding a response.
