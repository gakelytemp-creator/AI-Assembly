## Cross-critique question

For each of the three target statements, the critic is asked to identify: (1) one claim it would adopt or use to revise its own first-pass position; (2) one claim it rejects or considers under-specified, with reasons; and (3) one question it would send back to that participant. After all three, it must state whether its own first-pass position changes and list the exact changes. Consensus is not requested.
