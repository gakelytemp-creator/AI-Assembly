# Cross-Critique Relay Packets

These files are **operator relay packets** for Phase B.

They exist because some participant interfaces cannot open GitHub or external web links.

Each packet contains:

1. a common cross-critique instruction;
2. exactly three other participants' first-pass statements pasted in full;
3. explicit source delimiters so the participant can distinguish the three records.

The operator should paste a participant's packet directly into that participant's existing conversation where practical.

No web access is required by the participant.

The packet does **not** contain a chair summary and does not ask for consensus.

A participant's original first-pass statement remains unchanged even if the participant revises its position during cross-critique.
