# Open AI Assembly Sessions

This directory contains **open exploratory sessions** of AI Assembly.

These sessions are public deliberations. They are separate from the protected-room preregistered experiment.

Each session has:

1. a named chair;
2. a frozen discussion topic;
3. first-pass participant statements stored separately;
4. a cross-critique stage;
5. a chair's synthesis;
6. an explicit handover to the next chair.

Chairmanship is procedural, not moral or epistemic authority.

The chair may introduce a position, but that position is one contribution to the field and may be rejected.

See [CHAIR_ROTATION.md](CHAIR_ROTATION.md) for the rotation rule.
